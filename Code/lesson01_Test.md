# 第一课：什么是机器学习？

很多书第一句话都是：

> Machine Learning is the study of algorithms...

我不喜欢。

我更喜欢一句话：

> **机器学习就是让计算机自己寻找规律，而不是人写规则。**

举一个例子。

假设你写一个程序判断是不是垃圾邮件。

传统编程：

```cpp
if (包含"中奖")
    垃圾邮件;

if (包含"点击链接")
    垃圾邮件;
```

所有规则都需要程序员写。

机器学习则完全不同。

你准备：

```
100000封邮件
```

每封邮件都有标签：

```
垃圾邮件
正常邮件
```

然后告诉计算机：

```
请自己学习。
```

模型会自己找到规律。

以后再来一封新邮件：

```
Congratulations!
You win 1000 dollars!
```

模型就会输出：

```
垃圾邮件
```

而你从来没有写：

```
if 包含Congratulations
```

这就是机器学习。

## 一个更贴近你的例子

假设平台每天有一百万个视频。

平台希望：

> 哪些视频值得推荐？

传统方法：

```
播放超过1000
点赞超过100
推荐
```

这是规则。

机器学习：

输入：

```
标题
封面
发布时间
历史点击率
完播率
评论率
作者画像
```

输出：

```
推荐概率
```

模型自己学习。

这就是推荐算法。

而你的研究对象——平台算法治理——很多时候讨论的正是**模型如何学习、如何决策，以及这些决策如何影响创作者、消费者或执法对象**。因此，当我们后面讲到特征、训练数据、损失函数、过拟合等概念时，我也会顺带解释这些技术特性为什么会引发透明度、商业秘密、歧视或程序正义等法律问题。

# 机器学习到底学什么？

很多初学者误以为：

```
机器学习
=
神经网络
```

其实不是。

真正机器学习包括很多方法：

```
Linear Regression（线性回归）

Logistic Regression（逻辑回归）

Decision Tree（决策树）

Random Forest（随机森林）

SVM

KNN

Naive Bayes

Gradient Boosting

XGBoost

Neural Network（神经网络）
```

神经网络只是其中一种。

# 一个机器学习项目长什么样？

以后你会发现，几乎所有项目都是同一个流程：

```
        数据

         ↓

    数据清洗

         ↓

    特征工程

         ↓

    划分训练集

         ↓

      建立模型

         ↓

       训练模型

         ↓

      模型评估

         ↓

       调整参数

         ↓

      保存模型

         ↓

      用新数据预测
```

以后无论做房价预测、图片识别还是法律文书分类，流程几乎都一样。

# 今天真正的重点：学会 Jupyter Notebook

以后我们**90% 的机器学习代码都不会写在 `.py` 文件里**，而是写在 **Jupyter Notebook（`.ipynb`）** 中。

原因很简单：

Notebook 可以：

* 一段一段运行代码；
* 每一步立即看到结果；
* 插入文字、公式和图片；
* 特别适合数据分析和实验。

因此，从第二课开始，我们会主要使用 Notebook。

## 我们下一课会学什么？

下一课不会继续讲 Python，而是开始学习 **NumPy**。

原因可能和很多教程不同：**NumPy 才是机器学习真正的“母语”**。几乎所有机器学习框架（包括 scikit-learn、PyTorch、TensorFlow）都建立在数组和张量计算的思想之上。只要真正理解了 NumPy，后面学习深度学习会轻松很多。
